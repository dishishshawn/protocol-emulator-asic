# Fault-length sweep and live demo page

## Status
Done

## Requested outcome
An interactive demonstration of the stop-bit fault capture where every point is a
real simulation run, usable in the submission write-up (option A from the
roadmap; a bench demo stays deferred without hardware).

## Constraints and acceptance criteria
- Same engine, same host port: events read back through the capture FIFO.
- Sweep fault length across the receiver's sample point; several bytes.
- Page self-contained (evidence embedded), light/dark, phone width.

## Evidence gathered
- `fault_demo` drove the stop bit low for a whole bit only; the receiver samples
  16 clocks into the stop bit, so lengths 0–20 resolve the boundary.
- The capture FIFO holds eight entries and the host cannot drain a 32-clock bit
  cadence mid-run (a pop costs five exchanges of twelve clocks), so bytes are
  restricted to ≤ 8 edges per run; the test asserts no overflow.
- A fault of 64 clocks outlasts the modeled response unless idle is released and
  the wait starts immediately; `fault_demo` now does that for faults ≥ one bit.
